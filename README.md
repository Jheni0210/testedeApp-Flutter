# 📱 App Igreja – Flutter

Um aplicativo desenvolvido em **Flutter** com o objetivo de conectar membros à igreja, oferecendo informações, conteúdos espirituais e canais de comunicação.

---

## ✨ Funcionalidades

### 🏠 Tela de Apresentação
- Tela inicial com informações gerais da igreja
- Destaque para cultos e eventos importantes

### ⛪ Informações dos Cultos
- Horários atualizados dos cultos
- Detalhes sobre programações semanais

### 📖 Devocional (Bíblia)
- Página com **links para os livros da Bíblia**
- Acesso facilitado para leitura diária e devocional

### 📍 Localização da Igreja
- Integração com **Google Maps API**
- Visualização da localização da igreja no mapa
- Facilidade para traçar rotas

### 📧 Contato
- Tela para envio de **e-mails diretamente pelo app**
- Canal para dúvidas, pedidos ou comunicação com o responsável da igreja

### 📜 História da Igreja
- Página dedicada contando a **fundação da igreja**
- Informações sobre sua trajetória e missão

---

## 🚀 Tecnologias Utilizadas

- Flutter
- Dart
- Google Maps API
- Integração com e-mail (mailto ou API)
